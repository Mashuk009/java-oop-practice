# 01. Основы наследования

Консольная программа, которая читает список домашних питомцев и выводит их.

## Задача

Пользователь вводит количество питомцев, а затем для каждого: тип (`dog` или `cat`), имя и возраст. Программа проверяет ввод, создаёт объекты и выводит информацию о каждом питомце.

Обработка некорректного ввода:
- неподдерживаемый тип питомца: `Incorrect input. Unsupported pet type`
- возраст не больше нуля: `Incorrect input. Age <= 0`
- вместо числа введён текст: `Could not parse a number. Please, try again`

## Что показывает модуль

- абстрактный класс `Animal` с общими полями и методами;
- наследники `Cat` и `Dog`, вызов конструктора родителя через `super`;
- инкапсуляция: приватные неизменяемые поля (`private final`) и геттеры;
- переопределение `toString()`;
- работа с коллекцией `List<Animal>` через общий тип;
- чтение данных из консоли через `Scanner` и проверка ввода.

## Запуск

Из корня репозитория:

```bash
./gradlew :01-inheritance-basics:run
```

## Пример

Ввод:

```
3
dog Rex 5
cat Tom 0
cat Murka 3
```

Вывод:

```
Incorrect input. Age <= 0
Dog name = Rex, age = 5
Cat name = Murka, age = 3
```
