# 06. Собственный итератор

Консольная программа, которая читает список питомцев и выводит их с помощью самостоятельно написанного итератора.

## Задача

Пользователь вводит количество питомцев, а затем для каждого: тип (`dog` или `cat`), имя и возраст. Программа сохраняет питомцев в список и обходит его через собственную реализацию итератора вместо цикла `for-each`.

Обработка некорректного ввода:
- неподдерживаемый тип: `Incorrect input. Unsupported pet type`
- возраст не больше нуля: `Incorrect input. Age <= 0`
- вместо числа введён текст: `Could not parse a number. Please, try again`

## Что показывает модуль

- обобщённый интерфейс `BaseIterator<T>` с методами `next()`, `hasNext()` и `reset()`;
- его реализация `AnimalIterator` для списка животных (паттерн «Итератор»);
- работа с индексом текущей позиции и возврат в начало через `reset()`;
- юнит-тесты на порядок обхода, конец списка и сброс.

## Запуск

Из корня репозитория:

```bash
./gradlew :06-custom-iterator:run
```

Тесты:

```bash
./gradlew :06-custom-iterator:test
```

## Пример

Ввод:

```
2
dog Rex 5
cat Tom 3
```

Вывод:

```
Dog name = Rex, age = 5
Cat name = Tom, age = 3
```
