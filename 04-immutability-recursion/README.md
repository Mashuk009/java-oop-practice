# 04. Неизменяемость, рекурсия и Stream API

Консольная программа, которая читает список питомцев и увеличивает возраст тем из них, кому больше 10 лет.

## Задача

Пользователь вводит количество питомцев, а затем для каждого: тип (`dog` или `cat`), имя и возраст. Программа создаёт список питомцев, затем формирует **новый** список, где возраст каждого питомца старше 10 лет увеличен на 1, и выводит его. Исходные объекты не изменяются.

Обработка некорректного ввода:
- неподдерживаемый тип: `Incorrect input. Unsupported pet type`
- возраст не больше нуля: `Incorrect input. Age <= 0`
- вместо числа введён текст: `Could not parse a number. Please, try again`

## Что показывает модуль

- неизменяемые объекты: поля `final` и метод `withAge()`, который возвращает новую копию с другим возрастом;
- рекурсия: чтение питомцев (`readPets`) и ввод числа (`readInt`) реализованы без циклов;
- Stream API: `map` и `toList()` для преобразования списка;
- юнит-тесты на неизменяемость и на правило «старше 10 лет».

## Запуск

Из корня репозитория:

```bash
./gradlew :04-immutability-recursion:run
```

Тесты:

```bash
./gradlew :04-immutability-recursion:test
```

## Пример

Ввод:

```
3
dog Rex 12
cat Tom 3
cat Murka 11
```

Вывод:

```
Dog name = Rex, age = 13
Cat name = Tom, age = 3
Cat name = Murka, age = 12
```
