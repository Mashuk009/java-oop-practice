# 02. Полиморфизм: расчёт корма

Консольная программа, которая читает список питомцев и выводит для каждого рекомендуемое количество корма.

## Задача

Пользователь вводит количество питомцев, а затем для каждого: тип (`dog` или `cat`), имя, возраст и массу в килограммах. Программа выводит данные питомца и количество корма в килограммах.

Норма корма зависит от вида животного:
- кошка: 10% массы;
- собака: 30% массы.

Обработка некорректного ввода:
- неподдерживаемый тип: `Incorrect input. Unsupported pet type`
- возраст не больше нуля: `Incorrect input. Age <= 0`
- масса не больше нуля: `Incorrect input. Mass <= 0`
- вместо числа введён текст: `Could not parse a number. Please, try again`

## Что показывает модуль

- абстрактный метод `getFeedInfoKg()` в `Animal` и его разные реализации в `Cat` и `Dog`;
- полиморфизм: код в `Main` работает с `Animal`, не зная конкретного вида;
- форматированный вывод через `String.format` с `Locale.US` (точка в качестве разделителя дробной части);
- юнит-тесты на расчёт корма и формат вывода.

## Запуск

Из корня репозитория:

```bash
./gradlew :02-polymorphism-feeding:run
```

Тесты:

```bash
./gradlew :02-polymorphism-feeding:test
```

## Пример

Ввод:

```
2
dog Rex 5 10.5
cat Tom 3 4
```

Вывод:

```
Dog name = Rex, age = 5, mass = 10.50, feed = 3.15
Cat name = Tom, age = 3, mass = 4.00, feed = 0.40
```
