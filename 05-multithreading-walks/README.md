# 05. Многопоточность: прогулки питомцев

Консольная программа, в которой каждый питомец выходит на прогулку в отдельном потоке.

## Задача

Пользователь вводит количество питомцев, а затем для каждого: тип (`dog` или `cat`), имя и возраст. Все питомцы гуляют одновременно. Длительность прогулки зависит от вида и возраста:
- собака: возраст × 0,5 секунды;
- кошка: возраст × 0,25 секунды.

Когда питомец возвращается, программа выводит его данные, время начала и время окончания прогулки в секундах от запуска. Питомцы с короткой прогулкой выводятся раньше.

Обработка некорректного ввода:
- неподдерживаемый тип: `Incorrect input. Unsupported pet type`
- возраст не больше нуля: `Incorrect input. Age <= 0`
- вместо числа введён текст: `Could not parse a number. Please, try again`

## Что показывает модуль

- создание и запуск потоков (`Thread`), по одному на питомца;
- ожидание завершения потоков через `join()` с корректной обработкой `InterruptedException`;
- имитация длительной работы через `TimeUnit.MILLISECONDS.sleep()`;
- замер времени через `System.nanoTime()`;
- абстрактный метод `goToWalk()` с разной реализацией у `Cat` и `Dog`.

## Запуск

Из корня репозитория:

```bash
./gradlew :05-multithreading-walks:run
```

## Пример

Ввод:

```
2
dog Rex 2
cat Tom 3
```

Вывод (значения времени примерные, они немного отличаются от запуска к запуску):

```
Cat name = Tom, age = 3, start time = 0.00, end time = 0.75
Dog name = Rex, age = 2, start time = 0.00, end time = 1.00
```
